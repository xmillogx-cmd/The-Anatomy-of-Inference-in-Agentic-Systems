## Выводы (детали — conclusion.md, CONCLUSIONS.md C-21)

1. **TS batch=1 на consumer PCIe хуже SG во всех клетках** (tg TS/SG = 0.38–0.49); все 96 allreduces/token через host memory (P2P нет).
2. BW_eff Vulkan = 247.6 GB/s — ×0.553 spec; простой BW-модель не описывает Vulkan по всему S.
3. TS pp быстрее SG только в малом контексте (@S=1024: 5.4×); на длинном 0.61–0.74× SG.
4. Противопоставление C-18 (PP-CUDA): PP tg 33.19/26.89 @131k/262k f16 — выше даже TS-Vulkan; на consumer PCIe при batch=1 мульти-GPU не выигрывает ни в PP, ни в TS.
